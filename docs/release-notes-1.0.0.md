# 萌宠陪伴 1.0.0 发布说明

## 版本状态

`1.0.0` 是第一个可试用发布版本，面向 macOS。

## 核心功能

- 在 Dock 附近显示透明悬浮小猫。
- 自动跟随 Dock 所在屏幕。
- 小猫围绕活动中心小范围走动。
- 鼠标靠近后小猫停下看你。
- 单击小猫随机触发喵喵叫或倒地打滚。
- 双击小猫进入睡觉，再次双击恢复活动。
- 支持拖拽小猫到屏幕任意位置，并更新活动中心。
- 支持菜单栏暂停、恢复、立即校准 Dock、设置和退出。
- 支持设置移动速度、小猫大小、全屏空间显示、开机启动。

## 发布产物

```text
dist/1.0.0/萌宠陪伴-1.0.0.zip
dist/1.0.0/SHA256SUMS
```

在支持 `hdiutil` 的本机环境中，打包流程也会尝试生成：

```text
dist/1.0.0/萌宠陪伴-1.0.0.dmg
```

## 已知限制

- 当前小猫素材是项目内生成的占位精灵帧，不是最终商业美术资产。
- 当前发布包未做 Apple Developer 签名和公证，首次打开可能需要在 macOS 安全设置中允许。
- Windows 版本仍处于预研阶段。
